# 桌面伴侣 · Desktop Companion

一个常驻桌面的 2.5D 二次元助手。按住 Alt 说话，它会歪头听你；它站在任务栏上沿，
地面有影子，天气好的时候会自己发呆。

> 当前进度：**M1（会呼吸）+ 大脑 / 嗓子已通**。形象是程序化占位小人，等你的立绘接进来。
> 文字对话是通的、语音合成是通的、口型跟着音频包络走。
> 还缺两样：**麦克风（ASR）**，和**你自己的立绘**。

---

## 现在能做什么

- **透明置顶窗**：不进任务栏、不进 Alt+Tab，点空白处直接穿透到桌面
- **站在任务栏上**：窗口底边贴工作区底边，角色脚踩任务栏上沿
- **呼吸 / 眨眼 / 漂浮 / 头发滞后**：头发用独立弹簧，转头时晚半拍跟上来
- **会看你**：鼠标哪怕在窗口外，它也会转头（主进程 90ms 推一次全局光标）
- **按住 Alt 说话**：120ms 判定，Alt+Tab 之类组合键不会误触发
- **拖走它**：拖到哪记到哪，下次开机还在那儿
- **有人全屏就躲起来**：检测到全屏前台应用自动隐身，退出后自己回来
- **托盘常驻**：打盹（勿扰）、回到右下角、打开立绘文件夹、退出
- **漫画气泡**：带尾巴、逐字打出、淡入淡出
- **能说话了**：点它（或 Ctrl+Alt+Space）弹出输入条，回车 → 流式打字 → 出声 → 口型跟着声音动
- **声音是免费的**：Edge 在线合成，zh-CN-XiaoyiNeural 少女音，不需要 GPU、不需要 key
- **大脑可换**：DeepSeek / 任意 OpenAI 兼容端点 / Ollama 本地模型，改 `config.json` 一行

## 跑起来

```bash
cd desktop-companion
npm install
npm start
```

如果 `npm install` 之后报找不到 Electron，补一下二进制：

```bash
node node_modules/electron/install.js
```

## 快捷方式与开机自启

**桌面快捷方式**：托盘右键 → 「创建桌面快捷方式」，会在桌面放一个「桌面伴侣」，
双击就开，带自己的图标（`assets/icon.ico`，7 种尺寸打成一个 ico）。

**开机自启**：托盘右键 → 「开机自启（延迟 10 秒）」。它不写注册表，而是在
`%APPDATA%\…\Start Menu\Programs\Startup` 里放一个 `.lnk`，链路是：

```
桌面/启动文件夹\桌面伴侣.lnk
   →  wscript.exe          （系统自带，点击不被 SmartScreen 拦）
   →  tools/launch(-now).vbs   （开机那份先等 10 秒）
   →  tools/run.bat        （负责把 Electron 的输出重定向进 logs\console.log）
   →  electron.exe .
```

为什么绕这么大一圈，每一步都是被逼的：

| 环节 | 原因 |
|---|---|
| 不直接指向 `electron.exe` | 未签名的 exe 会触发 SmartScreen「已保护你的电脑」，点了「仍要运行」也未必真能起来 |
| 套一层 `.vbs` | 开机延迟 10 秒（避开登录风暴）；wscript 没有黑框；还能写痕迹日志 |
| `.vbs` 再套 `.bat` | `.bat` 的引号规则简单，而且能把 Electron 的 stdout/stderr 全量落盘 |

关掉：托盘取消勾选，或直接删启动文件夹里那个 `.lnk`。

### 起不来的时候怎么查

按顺序看 `logs\` 下的文件：

| 文件 / 内容 | 说明 |
|---|---|
| `boot.log` 里有 `launcher fired` | 快捷方式和 `.vbs` 都执行了 |
| `console.log` 里有 `===== … args=[…]` | `run.bat` 跑起来了 |
| `console.log` 里的 `exit code` | 非 0 就是 Electron 崩了，见下表 |
| `main.log` 里有 `app ready` | 应用初始化完成 |

**这台机器上必须带两个参数**（`run.bat` 里已经写死了）：

| 参数 | 不加会怎样 |
|---|---|
| `--no-sandbox` | Chromium 初始化就崩，退出码 `0x80000003`（-2147483645） |
| `--user-data-dir=…\data` | 默认 `%APPDATA%` 配置目录不可写，退出码 `-36861` |

这两个是层层暴露的：先解决沙箱才能看到第二个错误。

**踩过的坑（值得记住）**

1. 快捷方式直接指向未签名的 `electron.exe` → SmartScreen「已保护你的电脑」。
   指向系统自带的 `wscript.exe` 就不会触发。
2. `wscript` 用 ShellExecute 打开 `.bat` → 弹「无法验证发布者」。
   改成 `cmd /c run.bat`（CreateProcess）就不弹。
3. `.vbs` 只能用 ASCII 写。中文注释被 `'ascii'` 编码截成 `0x00` 字节，
   文件变二进制垃圾，WSH 直接解析失败，而且**没有任何报错**。
4. 用注册表 Run 项做开机自启，在这台机器上重启后进程根本没起来 ——
   现在是启动文件夹 + 10 秒延迟。

### 踩过的坑

1. `app.setLoginItemSettings()` 在开发态**调用不报错，但注册表里什么都不写**。
2. `reg add` 也不行：注册表值本身带引号，作为 `/d` 参数会被命令行的转义规则切碎。
3. 用 PowerShell 的 `-EncodedCommand`（base64）可以绕开所有引号问题。
4. **生成 `.vbs` 时只能用 ASCII**。之前注释里塞了中文，用 `'ascii'` 编码写出去时
   高位字节被截成 `0x00`，文件变成二进制垃圾，WSH 直接解析失败——
   于是开机时连痕迹都没有。现在 `.vbs` 里全是英文注释。

## 她能动什么

光会说话不够。接了 **function calling** 之后，她自己判断什么时候该动手：

| 工具 | 能做什么 | 限制 |
|---|---|---|
| `open_url` | 在默认浏览器打开网址 | **只允许 http/https**，`javascript:` / `file://` 一律拒绝 |
| `search_web` | 联网搜索，返回 5 条「标题 + 摘要 + 链接」 | 抓不到结果就退回打开浏览器，并说明原因 |
| `fetch_url` | 抓网页正文，转成纯文本给她读 | 只允许公网 http/https；**挡掉 localhost / 10. / 192.168. / 172.16-31.**；正文截断 3000 字 |
| `open_app` | 启动常用程序 | **白名单**：notepad / calc / paint / explorer / taskmgr |
| `open_folder` | 在资源管理器打开文件夹 | 路径必须真实存在且是目录 |

**典型链路**：用户说「查一下今天的新闻念给我听」→ `search_web` → 摘要不够 →
挑一条 `fetch_url` 抓正文 → 用自己的话转述（提示词里明确禁止念网址和列表编号）。

**工具循环**最多 4 轮：她可以「调工具 → 看结果 → 再说一句」，但有上限，
否则模型可能自己跟自己无限循环。

**为什么不给 `run_command`**：她能读记忆、能把你说的每句话存下来。一旦允许执行任意命令，
一句诱导就够把整台机器交出去。宁可手少，不能手松。

测试：`node -e` 里跑 10 条守边界的用例（拒绝 javascript: / file:// / 白名单外程序 / 不存在的目录…）。

## 记忆

它有记忆，而且你能直接打开来看、直接删。

**存什么**

| 层 | 内容 | 位置 |
|---|---|---|
| 短期 | 本次会话最近 8 轮 | 内存（`brain.js`） |
| 情节 | 所有对话，一行一条 | `memory/turns.jsonl` |
| 事实 | 从你说的话里抽出来的「关于你」，带权重和时间 | `memory/facts.json` |

**怎么抽事实**：规则匹配，刻意保守——

| 你说 | 它记住 |
|---|---|
| 我叫小周 | 用户叫 小周 |
| 我在字节工作 | 用户在字节工作 |
| 我喜欢二次元立绘 | 用户喜欢 二次元立绘 |
| 我讨厌别人叫我老板 | 用户不喜欢 别人叫我老板 |
| 记住：我周一到周四晚上有空 | 周一到周四晚上有空（权重最高，原样保留） |
| 你还记得我叫什么吗 | **不记**（疑问句会污染记忆，已过滤） |

**怎么用**：每次你开口，它按「话题相关度 + 权重 + 新鲜度」挑最多 5 条塞进上下文。
名字这类 profile 永远带上；无关话题不会硬翻旧账。

**跨会话**：隔 5 小时以上再见面，它会拿上次的话题开个头——
「小周，好久不见。上次你说『分层那步卡住了』，后来怎么样了？」

**忘掉**：托盘右键 → 记忆 → 忘掉聊过的事。文件也可以直接删。

> 没用向量库，是故意的。记忆量在几百条这个量级，字符二元组 + 时间衰减够用，
> 而且上向量就等于上原生依赖，这台机器装不动。真到了几千条再换。

## 接上大脑

打开 `config.json`，改这几行就行：

```json
{
  "brain": {
    "provider": "deepseek",
    "baseURL": "https://api.deepseek.com/v1",
    "model": "deepseek-chat",
    "apiKey": "sk-你的key"
  }
}
```

不想把 key 写进文件，就写占位符，运行时从环境变量取：

```json
"apiKey": "${DEEPSEEK_API_KEY}"
```

| provider | 说明 |
|---|---|
| `mock` | 默认值。本地假大脑，规则应答，用来验证整条管线跑不跑得通 |
| `deepseek` | 官方 API |
| `openai` | 任意 OpenAI 兼容端点，改 `baseURL` 即可 |
| `ollama` | 本地模型，`baseURL` 填 `http://127.0.0.1:11434/v1`，不需要 key |

没配 key 会自动退回 `mock`，日志里会说一声，不会崩。

### 密钥放哪（重要）

**不要把 key 写进 `config.json`。** 那个文件在仓库里，一旦提交，key 就永久留在 git 历史中了。

推荐放在机器级的私密文件：

```
%APPDATA%\desktop-companion\secrets.json
```

```json
{ "brain": { "apiKey": "sk-你的key" } }
```

`config.json` 里的 `apiKey` 留空即可，启动时会自动去这里取。优先级：

```
config.json 的 apiKey  >  secrets.json  >  ${环境变量}
```

上面任意一种都行，但**只有 secrets.json 和环变变量不会进仓库**。
`.gitignore` 里已经挡了 `config.secrets.json`、`*.secrets.json`。

## 声音

同样是 `config.json`：

```json
"voice": {
  "enabled": true,
  "voice": "zh-CN-XiaoyiNeural",
  "rate": "+6%",
  "pitch": "+4Hz",
  "volume": "+0%"
}
```

- 走 Edge 的在线朗读接口，**免费、不要 key、不要显卡**
- `zh-CN-XiaoyiNeural` 是活泼少女音，想换音色改名字即可
- 口型用的是真实音频包络（WebAudio `AnalyserNode`），不是随机开合
- 合成失败或机器没有音频设备时自动静音，只留气泡，不会把对话卡死
- 长回答会按句切开、一句一句合成播放，首句延迟更低

## 耳朵（语音识别）

按住 **Alt** 说话，松开就发。识别在本机跑，不联网、不上传。

| 项 | 值 |
|---|---|
| 引擎 | sherpa-onnx + SenseVoiceSmall（int8） |
| 模型 | 228 MB，`<工作区>/.asr-models/sense-voice/` |
| 速度 | 5.6 秒音频 → **0.22 秒**（RTF 0.04，纯 CPU） |
| 加载 | 1.4 秒，启动后 2.5 秒自动后台预热 |
| 顺带产出 | 语种、情绪标签（后面可以拿来调表情） |

配置在 `config.json`：

```json
"asr": { "enabled": true, "modelDir": "", "numThreads": 4, "language": "auto" }
```

`modelDir` 留空就自动找 `.asr-models/sense-voice`；`language` 可以锁 `zh` 提高中文准确率，
`auto` 会自己判语种（中英混说更好用）。

**失败了会怎样**：麦克风打不开、或者识别不出字，它会说一句"没听清"，然后把输入框递给你。
不会卡住，也不会静默失败。

**怎么测（不需要麦克风）**：

```bash
npx electron . --snapshot --bg=screen --voice=../.asr-models/sense-voice/zh.wav --shots=voice --outdir=snapshots/asr
```

这条命令会把 wav 从主进程塞进渲染进程，走完整的「识别 → 大脑 → 气泡」链路，
日志里能看到每一段耗时。

> 两个坑：① `sherpa.readWave` 在 Electron 主进程里会抛 `External buffers are not allowed`
> （纯 Node 里正常），所以改成了自己解析 WAV；② sherpa 返回的 samples 挂在 native 内存上，
> 直接过 IPC 也会被拒，得先逐元素搬进普通 Buffer。

**静音裁剪（VAD）**：录音先进 Silero VAD（644KB），切掉两端的空白再送去识别。

```
8.59s 录音 → 剪掉 4212ms 静音 → 识别 185ms
```

不剪的话，按住 Alt 等你想词的那两秒、说完还没松手的那一秒，都会被当成音频送进去——
既拖慢速度，也更容易把环境噪声识别成一句莫名其妙的话。实测 8.59 秒里有 4.2 秒是静音。

如果一句话都没检测到，它会直接说"没听到说话声"，而不是把一段噪声拿去猜。

## 什么时候开口

「室友型」最难的不是会说话，是知道什么时候闭嘴。`src/proactive.js` 只做一件事：
**决定现在能不能开口**，不产生内容。

| 限制 | 默认值 |
|---|---|
| 每天最多 | 2 次 |
| 距上次对话至少 | 40 分钟 |
| 两次主动之间至少 | 3 小时 |
| 静默时段 | 23:30 – 08:00 |
| 你离开座位（空闲 > 2 分钟） | 不说话 |
| 全屏 / 勿扰 / 正在对话 | 不说话 |
| 说一次「嘘」 | 当天永久闭嘴 |

而且**没有像样的理由就不吭声**。目前只认两种理由：你连续坐了 75 分钟、或者已经过了 23 点。
其他时候安静 —— 安静比搭话更像陪伴。

托盘右键 → 主动开口，能看到今天用了几次，也有「今天别说话」。

`npm run test:proactive` 跑 23 条断言（.tmp 文件，不依赖 Electron）。

## 深度分层（2.5D 视差）

单图只能整张一起动，看起来是"贴纸在呼吸"。把它按**深度**切成几层，每层位移量不同，
头就会比头发多飘几像素 —— 这是"体积感"的来源。

```bash
# 1. 抠图（ISNet-anime，CPU 约 1.2s）
python -u tools/matte_onnx.py 银月2.png work/2-matte.png

# 2. 按深度分层，顺便生成 manifest.json（约 1.5s）
python -u tools/depth_layers.py work/2-matte.png assets/character/layers 6
```

跑完之后 `assets/character/manifest.json` 会被写好，应用下次启动就用分层模式。

**它做了什么**

| 步骤 | 说明 |
|---|---|
| 深度估计 | Depth Anything V2 Small（ONNX，518 高，CPU 0.3s） |
| 归一化 | 只在角色内部取 2%~98% 分位拉伸，透明区域不参与 |
| 切层 | 按深度分位切成 N 层，每层像素数接近 |
| 补缝 | 每层 alpha 向外膨胀 14px —— 视差移动时相邻层会错开，不膨胀就露缝 |
| 投影 | 单独生成一层柔和投影垫底，浅色壁纸上白头发不至于糊掉 |
| 视差 | 最远层 0.12，最近层 1.15，线性递增 |

**两个必须记住的坑**

1. 膨胀要用**硬边**再乘原始 alpha。用羽化过的 mask 去截 alpha，几层半透明叠在一起
   会变成一层灰雾，整张脸都脏。
2. 平移不能用 `ImageChops.offset` —— 它会环绕，把画布底部的身体卷到头顶，
   画面上会出现一条贯穿的横线。

**尾巴慢半拍**

尾巴和外侧头发都在**最远的那几层**里，所以给越远的层挂越强的 `sway`（1.10 → 0.00），
再让它们吃一根独立的弹簧 `rig.tailX`（k=30, d=6.5，阻尼比 0.59）：

| 时刻 | 头 | 尾巴 | 落后 |
|---|---|---|---|
| 50ms | -1.41 | -1.81 | 7.2px |
| 200ms | 5.52 | 1.22 | 4.1px |
| 500ms | 6.58 | 5.52 | 跟上 |

过冲 0.95px，900ms 内收住。`npm run test:rig` 会把这些数字打出来。

> 关键：**不能只给尾巴加固定位移**。那样它永久比脸飘得更远，反而违反视差规律
> （越远应该动得越少）。必须是不影响稳态、只在运动时滞后 —— 靠弹簧的欠阻尼实现。

## 尾巴：真正独立的一根

之前尾巴只能跟整层一起平移，做不出"延迟半拍"的独立摆动。现在它是独立的一根。

**怎么切的**（`tools/split_tail.py`）

尾巴在最底层（01）里，和手臂、袖子同一张图，而且是「尾巴在手臂后面」的遮挡关系。
自动分割会把两者连成一片（试过连通域 + 深度阈值，失败），所以用多边形手工勾边界，
再把手肘那块被挡住的地方**用旁边的绒毛平移补上**。

产物：`layers/tail.png`（完整的尾巴）+ `layers/01_body.png`（去掉绒毛、保留手臂的身体）。

**绘制顺序**：尾巴画在身体**后面**。静止时被手臂挡住，摆动时从手臂后面探出来。

**两次失败**（都记在这里，别再踩）

1. **沿手臂挖个缺口** → 尾巴一旋转，那个手臂形状的空洞跟着转，-8° 时变成一道黑带。
2. **把多边形整块从身体里扣掉** → 连手臂一起删了，尾巴转开的地方露出黑色背景。

正解是第 3 版：尾巴补成完整形状（无洞），身体保留一圈**内缩 15px 的衬底**，
只去掉绒毛的外环。这样尾巴转开时露出来的是毛，不是黑洞。

**弹簧**（`rig.js`）

```js
this.tailAngle = new Spring({ k: 13, d: 3.2 })   // 单位是度
```

`k` 刻意压得比头发还低。实测：

| 指标 | 数值 |
|---|---|
| 最大摆角 | 4.7°（`maxAngle` 限 6°） |
| 到达终值 90% | 尾巴 280ms vs 头 0ms → **落后 280ms** |
| 回摆过冲 | 0.6° |
| 静止 | 0 附近 ±1° 微晃（两段正弦叠加） |

`npm run test:rig` 里 6 条断言守着这些数字。

## 换成你的图

把图丢进 `assets/character/` 就行，不用改代码：

- 一张透明 PNG 命名为 `base.png` → 单图模式（自动呼吸、漂浮、贴合地面）
- 或者放 `manifest.json` + 分层 PNG → 逐层视差、头发独立摆动

详细要求见 [`assets/character/README.md`](assets/character/README.md)。

## 开发自检

没有第二块屏幕、或者懒得点的时候，可以命令行截图：

```bash
# 截四个状态（透明背景）
npx electron . --snapshot --bg=none --shots=idle,listening,thinking,speaking --outdir=snapshots/final

# 看命中区（绿色椭圆 = 可点击范围）
npx electron . --snapshot --bg=checker --hitbox --shots=idle

# 拼成预览图
python tools/make-preview.py snapshots/final preview.png
```

参数：

| 参数 | 说明 |
|---|---|
| `--snapshot` | 截完图自动退出 |
| `--bg=none\|checker\|dark\|screen` | 换底色，`checker` 最容易看清透明边缘 |
| `--shots=a,b,c` | 依次切状态各截一张 |
| `--hitbox` | 画出命中区 |
| `--smoke` | 真的以托盘方式跑 5 秒再退出，检查钩子/托盘/侧车是否都起来了 |

日志写在 `logs/main.log`。

## 已知限制

- **不会眨眼、不能对口型**：银月是 3D 渲染风，眼睛和皮肤是连续渐变，
  挖一层换帧会露出接缝。平涂立绘才能做这件事。
- **记忆是规则抽取，不是理解**：只认几种固定句式（我叫/我在…工作/我喜欢/记住：…），
  说得太绕会漏。宁可漏也不乱记——记忆里塞满废话比没记忆更像智障。
- **主动开口只会说两句**：连续坐太久、太晚了。没有接日程/待办/屏幕内容，
  所以它还不会说"你那个会要开始了"。接上工具调用之后才有意义。
- **拖拽的兜底**：鼠标如果在窗口外松开，靠「200ms 不动」来结束拖拽；
  接入全局钩子后已经能用全局 mouseup 正确收尾，但窗口快速甩出去时仍可能有一帧延迟。
- **全屏检测依赖 PowerShell 侧车**：某些把 TEMP 目录锁死的环境里 `Add-Type` 会失败，
  这时自动隐身失效（不会崩）。已把侧车的 TEMP 指到项目内 `logs/ps-tmp` 规避。
- **在没有 GPU 的机器上**：渲染是 Canvas2D 软件绘制，够用；后续上法线光照再考虑 WebGL。
