# 把你的图放这里

程序启动时会自动探测这个文件夹，按下面的顺序决定用哪种模式。

## 模式一：单图（最简单）

把一张 **透明背景 PNG** 命名为 `base.png` 丢进来即可。

- 推荐尺寸：高度 ≥ 1200px，宽高比 2:3 左右
- 必须是透明背景（白底也行，但白框会显示出来）
- 程序会自动缩放到约 316px 高，贴地放在窗口底部
- 会自动加呼吸、漂浮、轻微转头和地面阴影

**半身像特别注意**：如果图是腰以上就切掉的半身像，程序会让底边压到窗口下沿之外，
正好藏进任务栏后面 —— 切边看不见，看起来像她站在任务栏后面。所以半身像反而比全身像好看。
（当前这张银月就是半身像模式，窗口高度 620，角色高约 420，头顶留出气泡位置。）

## 模式二：分层（效果好，推荐）

放一个 `manifest.json`，并把各层 PNG 一起放进来。参考 `manifest.example.json`。

**关键约定：所有图层请导出成同一块画布的透明 PNG**（尺寸完全一致、位置对齐），
这样你不需要在配置里写每层的坐标，程序直接叠上去就行。这是最省事、
也最不容易出错的做法 —— 在 Photoshop / Clip Studio 里把每个部件单独导出为
「整画布 PNG」即可。

建议的图层顺序（从后到前）：

| 文件 | 部件 | 建议 parallax | 建议 sway |
|---|---|---|---|
| `00_shadow.png` | 地面阴影（可选，程序会自动生成） | 0 | 0 |
| `01_hair_back.png` | 后发 | 0.35 | 0.6 |
| `02_body.png` | 身体 / 衣服 | 0.25 | 0 |
| `03_face.png` | 脸（含耳） | 1.0 | 0 |
| `04_eyes_open.png` | 睁眼 | 1.0 | 0 |
| `05_mouth_closed.png` | 闭嘴 | 1.0 | 0 |
| `06_hair_front.png` | 刘海 / 侧发 | 0.8 | 1.0 |
| `07_ahoge.png` | 呆毛 | 0.6 | 1.4 |

- `parallax`：跟随头部移动的强度（0 = 不动，1 = 完全跟随）。越靠前的部件越大。
- `sway`：额外的头发式摆动强度，让部件比头慢半拍。

> M1 阶段只做了「逐层视差 + 弹簧摆动」。眼睛/嘴巴换帧、口型驱动在 M3 接上。

## 没有图的时候

程序会用一个程序化的占位小人（会呼吸、眨眼、转头、头发会晃）。
这个占位只是为了验证管线，不是最终形象。
